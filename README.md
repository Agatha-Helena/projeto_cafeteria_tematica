Cafeteria Minduim ☕

Site de cardápio para uma cafeteria com identidade visual inspirada no persongaem Snoopy.
Projeto feito com Bootstrap para a Somativa 2 do Prof. Marlon.


Funcionalidades:
Cardápio dinâmico: os pratos são objetos da classe Alimento (nome, preço, categoria, imagem) e os cards são gerados via JavaScript.
Filtro por categoria: botões "Todos / Salgados / Doces / Bebidas" acima do cardápio.

Tecnologias:
HTML5 + CSS3
Bootstrap 5 (grid, navbar, modal)
JavaScript (classes, manipulação de DOM)
